Hello, this is the Open Platform Developer Community.

The OPDC website has been completely renewed.

---

## New Features

### 1. News & Announcements Tab Restructure
- **News/Announcements Tab**: Existing blog content
- **Videos Tab**: YouTube channel videos (Videos, Shorts, Playlists)
- **Facebook Tab**: Facebook page feed integration

### 2. YouTube Auto Sync
- New channel videos are automatically added to the website
- Auto-categorization of Videos/Shorts/Playlists

### 3. Homepage Latest News Integration
- Blog announcements and YouTube videos displayed together by date

### 4. Responsive Design
- Full support for mobile, tablet, and desktop

### 5. Multi-language Support
- English pages added (EN/KO toggle)

### 6. Performance Optimization
- Fast page loading speed
- Image lazy loading
- SEO optimization

### 7. Leaders Carousel
- Leader introductions in slide format
- Random order display

### 8. Search Function
- News/Announcements post search
- Search by title, description, and content

### 9. Release Notes
- Version update history page added
