OPDC 홈페이지가 전면 리뉴얼되었습니다.

---

## 새로운 기능

### 1. 소식/공지 탭 구조 개편
- **소식/공지 탭**: 기존 블로그 콘텐츠
- **영상 탭**: YouTube 채널 영상 (동영상, Shorts, 재생목록)
- **Facebook 탭**: Facebook 페이지 피드 연동

### 2. YouTube 자동 동기화
- 채널의 새 영상이 자동으로 홈페이지에 추가
- 동영상/Shorts/재생목록 자동 분류

### 3. 홈페이지 최신 소식 통합
- 블로그 공지와 YouTube 영상을 날짜순으로 통합 표시

### 4. 반응형 디자인
- 모바일, 태블릿, 데스크톱 완벽 대응

### 5. 다국어 지원
- 영문 페이지 추가 (EN/KO 전환)

### 6. 성능 최적화
- 빠른 페이지 로딩 속도
- 이미지 지연 로딩
- SEO 최적화

### 7. 리더 캐러셀
- 리더 소개 슬라이드 형식으로 개선
- 랜덤 순서로 표시

### 8. 검색 기능
- 소식/공지 게시글 검색
- 제목, 설명, 본문 내용 검색 지원

### 9. 릴리즈 노트
- 버전별 업데이트 내역 페이지 추가
