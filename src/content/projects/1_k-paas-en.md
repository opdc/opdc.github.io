### Project Overview

- Shell scripts based on Vagrant and VirtualBox for running K-PaaS locally
- Fully automated by default (auto-installs everything on execution)
- Improved user accessibility and understanding through local K-PaaS installation
- Troubleshooting guide for installation errors
- K-PaaS version (v1.5.2) applied
