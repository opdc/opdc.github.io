## 수정 사항

### 🐛 버그 수정

- **언어 전환 URL 오류 수정**
  - 영문 리더 상세 페이지(`/en/leaders/`)에서 한국어로 전환 시 존재하지 않는 페이지로 이동하던 버그 수정
  - 영문 슬러그(`05-lee-kiha-en`)에서 `-en` 접미사를 제거해 올바른 한국어 URL(`/leaders/05-lee-kiha/`)로 이동하도록 수정
  - 한국어 리더 페이지에서 영문으로 전환 시에도 정확한 영문 URL로 이동하도록 수정

### ♻️ 코드 개선

- `src/lib/i18n.ts` 유틸 추가: `toKoSlug()` / `toEnSlug()` 함수로 `-en` 슬러그 변환 로직 중앙화
  - 기존 4곳에 분산된 인라인 `.replace(/-en$/, '')` 호출을 일괄 교체
