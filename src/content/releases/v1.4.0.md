## 새로운 기능

- **소식/공지 탭 구조 개편**
  - 소식/공지 탭: 기존 블로그 콘텐츠
  - 영상 탭: YouTube 채널 영상 (동영상, Shorts, 재생목록)
  - Facebook 탭: Facebook 페이지 피드 연동

- **YouTube 자동 동기화**
  - 채널의 새 영상이 자동으로 홈페이지에 추가
  - 동영상/Shorts/재생목록 자동 분류

- **홈페이지 최신 소식 통합**
  - 블로그 공지와 YouTube 영상을 날짜순으로 통합 표시

## 개선 사항

- 리더 스키마 정리 (미사용 필드 제거)
