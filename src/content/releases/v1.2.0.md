## 새로운 기능

- **호환성확인 페이지**: 전자정부 표준프레임워크 호환성 확인 서비스 연동
- **오픈커뮤니티 페이지**: 오픈커뮤니티 콘텐츠 연동
  - 공지사항, 기술세미나, 자료실 탭
  - 첨부파일 아이콘 표시
- **다국어 지원**: 영문 페이지 추가 (EN/KO 전환)
- **릴리즈 노트**: 웹사이트 변경 이력 페이지

## 개선 사항

- 헤더에 언어 전환 버튼 추가
- 메뉴 및 푸터 영문 번역
- 매일 오전 3시(KST) 자동 빌드로 최신 게시글 반영
