# Design Asset Attribution Register

This register is intentionally conservative. Prefer original OPDC assets and CSS/SVG generated in this repository.

| Asset / dependency | Source | License | Usage rule |
|---|---|---|---|
| Pretendard | https://github.com/orioncactus/pretendard | SIL Open Font License 1.1 | Existing site dependency; retain license terms when redistributing font files. |
| Tailwind CSS | https://github.com/tailwindlabs/tailwindcss | MIT | Existing build dependency; no copied upstream UI required. |
| Lucide | https://github.com/lucide-icons/lucide | ISC | Generic interface icons only; no brand-logo substitution. |
| OPDC existing images | `public/img/**` | OPDC project assets / verify per asset | Prefer these assets over external imagery. |

## Reuse policy

- Do not import competitor screenshots, logos, illustrations, or CSS as production assets.
- Do not hotlink third-party artwork into the redesigned hero.
- Record any new external asset here before merging.
- For project or company logos, verify trademark/brand-use requirements separately from software license terms.
