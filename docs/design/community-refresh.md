# 커뮤니티 디자인 수정

범위는 `/redesign` 전용 레이아웃, 홈, 스타일에 한정한다. 기본 홈과 기존 운영 경로는 변경하지 않는다.

- 첫 화면: 한국어 소개, 최신 소식, 프로젝트·커뮤니티·호환성확인 진입점.
- 기존 최신 영상, 프로젝트, 게시글, 리더 데이터와 링크 유지.
- 흰색 / 옅은 회색 / 남색 / 주황색, Pretendard, 최대 콘텐츠 폭 1200px.
- 본문 보조 글씨 확대, 메뉴 대문자 스타일 제거, 푸터 대비 보완.
- 리더 목록은 자동 이동 대신 가로 스크롤과 전체보기 링크 제공.
- 기존 프리뷰의 라이트 테마 유지. 다크 OS 설정에서도 동일한 라이트 화면 제공.

검증: `pnpm build`, 브라우저에서 홈·목록·상세 경로와 모바일 메뉴, axe 접근성, 기본 경로 변경 여부 확인.
